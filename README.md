> Plataforma web moderna y estática (Landing Page) diseñada para la clínica veterinaria "Pocas Pulgas". 

Este proyecto proporciona una interfaz profesional y responsiva para que los clientes puedan visualizar información sobre sucursales, especialidades médicas, servicios de urgencias y vías de contacto directo.

---

## 🌟 Características Principales

- **Diseño Responsivo:** Adaptable a dispositivos móviles, tablets y computadoras.
- **Interfaz Moderna:** Basada en la estructura funcional de clínicas veterinarias reales.
- **Rendimiento:** Carga ultra rápida gracias a la implementación de Vite.
- **Arquitectura Limpia:** Proyecto 100% Frontend sin dependencias complejas de servidor.

---

## 🛠️ Requisitos Previos

Para ejecutar este proyecto de manera local en tu computador, necesitas tener instalado:

*   [Node.js](https://nodejs.org/) (incluye el gestor de paquetes npm)
*   [Git](https://git-scm.com/)

---

## 🚀 Instalación y Despliegue Local

Sigue estos pasos en tu terminal para correr la página en tu máquina:

**1. Clonar el repositorio y entrar a la carpeta del proyecto:**
```bash
git clone https://github.com/OrionRV6/PocasPulgas.git
cd PocasPulgas/veterinaria-app
```

**2. Instalar las dependencias de Node:**
```bash
npm install
```

**3. Iniciar el servidor de desarrollo:**
```bash
npm run dev
```

🌐 **¡Listo!** La plataforma estará disponible inmediatamente abriendo `http://localhost:5173` en tu navegador.
